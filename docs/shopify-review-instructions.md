# Qalt — Shopify App Review Instructions

## Review context

This app is presented as a **quote-only flow** on the free **Starter** plan for the purposes of Shopify review.

- The free Starter plan does **not** require payment.
- Reviewers do **not** need Stripe or any checkout flow to complete testing.
- Pro and Enterprise plans include payment features, but those are **not** required for review.
- The reviewer can complete all testing using only the Starter plan.
- The review flow is **quote submission only**.

## Testing instructions

This app includes a free Starter plan that does not require payment.

1. Install and open the app from the admin panel.
2. The app loads on the Starter plan by default.
3. Open the quote calculator.
4. Enter a pickup and delivery address.
5. Confirm the route and delivery amount appear.
6. Submit the quote.
7. Open the dashboard.
8. Confirm the new request appears under recent requests.

## Notes for reviewers

- The widget button label on the Starter plan reads **"Submit Quote"** — there is no payment step.
- **"Pay & Book"** only appears when a merchant upgrades to Pro or Enterprise and explicitly enables payments. This path is not required for review.
